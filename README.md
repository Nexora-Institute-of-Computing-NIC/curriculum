# Nexora Institute of Computing - Curriculum Map

A complete **8-semester, 80-subject Computer Science & Engineering curriculum**,
built in the open. Every subject has its own repository with theory, labs,
assignments, and a `PLAN.md` describing the syllabus.

## Summary

- **80 subjects** across **8 semesters**
- Every subject has a `PLAN.md` with units, lecture titles, 15+ labs, and assignments

## How to use this curriculum

1. **Pick a semester** - start at Semester 1 if you are new to programming.
2. **Read the `PLAN.md`** - it lists every lecture, lab, and assignment.
3. **Work through the theory** - `theory/` in each subject repo.
4. **Do the labs** - `labs/` in each subject repo, with starter code and tests.
5. **Build the project** - `project/` in each subject repo.
